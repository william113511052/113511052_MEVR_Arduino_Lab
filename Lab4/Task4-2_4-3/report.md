## Bonus Task 4-2: Ball-on-Beam Project
### 1. 實驗目標
- 實作「Ball-on-Beam」機電系統，利用超音波感測器量測球體位置，並以 PID 控制演算法驅動伺服馬達，將球體穩定維持在目標位置。
- 實作進階的感測器訊號處理（中值濾波與移動平均），解決超音波感測器易受雜訊與突波干擾的問題。
- 處理 PID 控制常見的實務問題，如積分飽和（Integral Windup）與高頻微分雜訊。

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- HC-SR04 超音波感測器 x 1（Trig: Pin 10, Echo: Pin 11）
- SG90 伺服馬達 x 1（Pin 9）
- 麵包板、杜邦線、3D列印軌道與乒乓球

### 3. 操作說明與成果
1. **訊號濾波與感測**：
   - 系統以 50ms (`SAMPLE_MS`) 為週期讀取 HC-SR04。
   - 實作雙重濾波機制：先以 3 點中值濾波器 (`median3`) 剔除極端突波，再透過 4 點移動平均濾波器 (`N_AVG = 4`) 平滑數值。此外，加入跳值保護機制 (`JUMP_CM = 3.0`)，當讀值瞬間跳動超過 3cm 時暫時沿用前次有效值。
2. **PID 控制核心**：
   - 基準水平角度設定為 120 度 (`baseAngle`)，最大傾角補償限制為 ±17 度 (`TILT_LIMIT`) 以保護機構。
   - **防積分飽和**：僅當誤差在 3.0cm 內 (`I_BAND`) 才進行積分，並加入積分上下限 (`I_LIMIT = 5.0`)。
   - **微分低通濾波**：對微分項加入平滑濾波 (`D_ALPHA = 0.5`)，避免伺服馬達因距離微小抖動而劇烈抽搐。
3. **實驗成果**：
   - 最終調校的 PID 參數為 **Kp = 2.0, Ki = 0.7, Kd = 4.5**，目標點設定為距離感測器 **10.5 cm** 處。系統能快速且平穩地將球體收斂至目標點，且馬達無異常高頻抖動。

## Bonus Task 4-3: Free Development Project
### 1. 實驗目標
- 導入非阻塞式多工架構（Non-blocking Architecture），使用 `millis()` 獨立排程不同的任務。
- 開發 C# 或序列埠即時調參介面 (Serial Command Tuning) 與即時數據繪圖輸出 (Telemetry)，以提升 PID 調校效率與系統觀測性。

### 2. 設備與元件
- 延續 Task 4-2 設備
- Arduino IDE Serial Monitor / Serial Plotter

### 3. 操作說明與成果
1. **多工架構實作**：
   - 將主程式 `loop()` 拆分為三個獨立任務：`taskSerial()` 處理外部指令、`taskControl()` 負責 50ms 週期的運算、`taskTelemetry()` 負責資料回報。系統運作不再依賴會阻塞程式的 `delay()`。
2. **即時調參指令系統 (taskSerial)**：
   - 開發序列埠字串解析功能，可於系統運作中動態修改參數。
   - 支援指令集包含：修改 P/I/D 參數 (`p`, `i`, `d`)、修改目標距離 (`s`)、微調基準角度 (`b`)、調整回報速率 (`t`) 以及重置積分項 (`r`)。例如輸入 `s15` 即可讓球體立刻移至 15cm 處。
3. **即時觀測繪圖 (taskTelemetry)**：
   - 將當前目標距離 (`target`)、實際距離 (`pos`) 與輸出傾角 (`tilt`) 以 `name:value` 的格式輸出至序列埠。
   - 可直接配合 Arduino Serial Plotter 繪出即時響應曲線，直觀地觀察超調量 (Overshoot) 與收斂時間。
4. **實驗成果**：成功透過軟體擴充賦予系統極高的調校便利性，在不重新燒錄程式的情況下，即可觀察響應曲線並動態尋找最佳 PID 參數。
