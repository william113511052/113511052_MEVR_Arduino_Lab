## Advanced Task 2-1: DC Motor Control with a Variable Resistor
### 1. 實驗目標
- 結合可變電阻 (電位器) 控制直流馬達。
- 透過讀取可變電阻數值，同時控制馬達的**旋轉方向**與**轉速**。

### 2. 設備與元件
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1
- Arduino Uno 開發板 x 1
- 直流馬達、L293D 馬達驅動 IC
- 可變電阻 x 1
- 麵包板 x 1
- 杜邦線 若干

### 3. 操作說明與成果
1. **控制邏輯**：讀取可變電阻的類比值 (0~1023)。將中間點 (例如 512 左右) 設為停止狀態。低於中間值時控制馬達順時針旋轉，越低轉速越快；高於中間值時控制馬達逆時針旋轉，越高轉速越快。
2. **程式撰寫**：將類比數值映射 (map) 成對應的 PWM 數值，並輸出至 L293D 的 Enable 腳位 (需接支援 PWM 的 pin) 或控制腳位。
3. **實驗成果**：轉動可變電阻旋鈕時，能順暢改變馬達的轉速與方向。
