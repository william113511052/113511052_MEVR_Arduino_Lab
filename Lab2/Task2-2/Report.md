## Advanced Task 2-2: Servo Motor Control with an Ultrasonic Sensor
### 1. 實驗目標
- 結合 HC-SR04 超音波感測器與 SG90 伺服馬達。
- 依據超音波感測器測得的**距離**，即時對應並控制伺服馬達的**角度**。

### 2. 設備與元件
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1
- Arduino Uno 開發板 x 1
- SG90 伺服馬達 x 1
- HC-SR04 超音波感測器 x 1
- 麵包板 x 1
- 杜邦線 若干

### 3. 操作說明與成果
1. **電路連接**：HC-SR04 的 Trig 與 Echo 接腳分別連接至 Arduino 指定腳位，並與伺服馬達共同接妥電源。
2. **程式撰寫**：計算超音波回波時間得出距離 (公分)。利用 `map()` 函式將距離數值映射至伺服馬達的角度範圍 (0~180度)，並加入 `constrain()` 避免數值溢出。
3. **實驗成果**：當手或物體靠近/遠離超音波感測器時，伺服馬達的角度會隨距離即時改變。
