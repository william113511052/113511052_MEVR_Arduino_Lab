## Advanced Task 1-2: RGB LED Lighting
### 1. 實驗目標
- 綜合運用數位輸入、類比輸入與序列埠輸入。
- 透過三種不同的輸入方式，分別控制 RGB LED 的紅 (R)、綠 (G)、藍 (B) 三色，達成顏色疊加與混色效果。

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- RGB LED x 1
- 按鍵開關 x 1、可變電阻 x 1
- 限流電阻 x 3、下拉電阻 x 1
- 杜邦線 若干

### 3. 操作說明與成果
1. **電路連接**：
   - 確認 RGB LED 為共陰極或共陽極（將最長腳接 GND 或 5V）。
   - R、G、B 控制腳位分別串接限流電阻後接至 Arduino 的 PWM 腳位。
   - 連接按鍵開關與可變電阻。
2. **控制邏輯**：
   - **Blue**：由可變電阻 (Analog Input) 讀值控制亮度。
   - **Red**：由按鍵開關 (Digital Input) 控制亮滅。
   - **Green**：由序列埠 (Serial Input) 接收指令控制。
3. **實驗成果**：
   - 單獨轉動旋鈕時亮起藍光。
   - 轉動旋鈕並按下按鍵時，藍光與紅光疊加呈現紫光。
   - 於前述狀態下再由 Serial Monitor 輸入字元 "1" 啟動綠光，三色疊加呈現白光。
